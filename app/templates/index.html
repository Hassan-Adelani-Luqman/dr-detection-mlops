Diabetic Retinopathy Detection

An MLOps deployment that grades retinal fundus images across five severity levels, accepts new labelled data from the field, and retrains on demand — built to support scalable, accessible diabetic retinopathy screening across Africa, where specialist ophthalmologists are scarce.

👁  Predict

Upload a fundus image and get its DR grade (0–4) with per-class confidence and a clinical action note.

↑  Upload

Contribute labelled images to the training pool, stored in the database for future retraining.

↻  Retrain

Fine-tune a new model version from the pool using the active model as a pre-trained base. The original is never overwritten.

📊  Insights

Explore dataset distribution, baseline metrics, and the full model version history — with one-click rollback.

How retraining works

  1. Collect — labelled fundus images are uploaded and saved to the database, joining a balanced replay buffer.
  2. Preprocess — each image is converted to the exact format the model was trained on (RGB, 224×224, normalised).
  3. Fine-tune — the convolutional backbone is frozen and only the classifier head is trained, keeping retraining fast on CPU.
  4. Version & promote — a new versioned model is saved and promoted to active; any prior version can be restored.
